# Qairu Space 2.1.0

Авторы: **wateroff и airsmooth**. Неофициальное расширение для campus.qairu.edu.kz.

Тема Lunatica объединена с экзаменами в сетке расписания, дедлайнами, заметками, историей изменений расписания и переносом настроек Campus Night. Графитовая, тёплая и полуночная палитры; режимы тёмный, системный и выключенный.

Рейтинг XP — добровольная бета. Псевдоним, существующий XP, место и тир кампуса; значения присланы расширением и не подтверждены университетом. Проверки личности нет. Участие, обновление XP и удаление — по явной кнопке. Ключ управления переносится отдельным файлом.

Сравнение оценок и GPA — отдельная добровольная бета. Точные значения хранятся в закрытой базе; участник видит только собственный диапазон при выборке от 20 человек. Отдельное согласие на период, ежедневная проверка при открытом кампусе, пауза, удаление и перенос отдельным ключом. Пока поддержаны результат предмета, однозначные квизы и GPA в русском интерфейсе; работы без надёжного идентификатора исключаются.

## Обновление

Устанавливайте обновление из той же карточки Firefox / Chrome поверх Campus Night. Идентификаторы расширения и ключи хранилища сохранены. Не удаляйте старое расширение перед обновлением. Импорт резервных копий v1/v2 поддерживается; обычная копия не включает ключ рейтинга. Настройки отдельного userscript автоматически не переносятся.

## Сборка

Node.js 22.23.2, npm. В корне репозитория:

```sh
npm ci
npm test
npm run build
node scripts/build-worker.cjs
```

Пакеты: dist/firefox и dist/chromium. Сервер: server/worker.mjs, инструкция docs/DEPLOYMENT.md. Код расширения находится в extension; тесты используют синтетические данные.

## Происхождение

[Lunatica от wateroff](https://www.wateroff.dev/qairu-campus-extension), сохранённый исходник lunatica.user.js и происхождение UPSTREAM.md. В расширение включён движок оформления; отдельная панель и настройки userscript не запускаются параллельно.
