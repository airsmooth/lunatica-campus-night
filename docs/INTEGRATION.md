# Lunatica и Campus Night: направление интеграции

Это план дальнейшего развития, не список уже перенесённых функций.

| Возможность | Lunatica 2.0.1 | Campus Night 1.4.0 |
|---|---|---|
| Тема | Переменные кампуса, палитры и коррекция CSS/inline-цветов | Dark Reader и палитры |
| Видимость сайта | Переключатели меню, блоков главной, шапки, Aya | Масштаб, широкая область, Aya, уменьшение движения |
| Расписание для передачи | PNG, текст/буфер обмена, JSON видимой недели | ICS экзаменов |
| Экзамены | Специального модуля сопоставления с PDF не найдено | Поток/практика, проверка PDF, сетка, новые таблицы |
| Дедлайны и работа над заданиями | Специальных модулей не найдено | Точное время, личные статусы/заметки |
| Хранение | GM_getValue/GM_setValue, lx.settings.v2; чтение старого qd.settings.v1 | browser.storage.local, собственные ключи и JSON-перенос |

Рекомендуемая основа оформления: переменные и переключатели Lunatica. Учебные модули сохранять из Campus Night. Два движка темы одновременно не включать. Экспорт расписания в PNG/текст полезен для обмена с одногруппниками.

Перед выпуском объединённого расширения:

1. Адаптировать GM-хранилище и меню к WebExtension API без потери текущих настроек. Использовать существующие ID магазинов и обратную совместимость копий JSON.
2. Разделить оформление, настройки и экспорт расписания на модули. Сохранить оформление под кампус, отключать декоративные эффекты по умолчанию.
3. Проверить собственные Shadow DOM панели, тетради/редакторы, статусы, графики, смену страниц и влияние наблюдателей DOM/CSS на производительность.
4. Проверить внешние URL фона/аватара: в скрипте нет fetch/XHR, но CSS с пользовательским URL может делать сетевые запросы. Не заявлять полное отсутствие сети. Учитывать это в настройках, CSP и политике расширения.
5. Сохранить обе лицензии, проверить воспроизводимую сборку Firefox/Chromium и отправить обновление в оба существующих магазина после реализации и проверки.

Ни установка, ни интеграция, ни новый выпуск в магазины на этапе создания форка не выполнялись.
