# Qairu Space: объединённое расширение и добровольный XP-рейтинг

Статус: проект для согласования. 13 ноября 2026.

## Задача и подтверждённые решения

Объединить оформление Lunatica от wateroff с учебными возможностями Campus Night 1.4.0. Название — **Qairu Space**, авторы — wateroff и airsmooth. Сохранить установленные расширения и пользовательские настройки при обновлении в Firefox и Chromium. Пользователь предпочитает оформление кампуса, без отдельного декоративного дашборда.

Добавить добровольную бету сравнения **существующего XP кампуса**: псевдоним, место и тир среди присоединившихся, выход с удалением записи. Пользователь подтвердил такой вариант и исключил оценки из этого выпуска. XP не начисляется расширением. Значения присланы расширением и не проверены университетом; это явно написано при вступлении и в рейтинге.

## Подходы и границы

Подтверждён вариант добровольной онлайн-беты с указанными ограничениями. Локальное отображение собственного XP не позволяет сравнивать участников. Официально проверенный рейтинг потребовал бы интеграции с университетом, которой сейчас нет. Не обещать защиту от накрутки или правило «один человек — одна запись»: без идентификации оно не обеспечивается.

Для объединения интерфейса используем тему и переменные Lunatica, адаптированные к WebExtension, и существующие учебные модули Campus Night. Два движка оформления одновременно не запускаются. Простая установка двух отдельных расширений не удовлетворяет задаче единого интерфейса и миграции настроек.

Технические решения ниже выбраны исполнителем: Cloudflare Worker + D1 для общей таблицы; прежние ключи хранилища для совместимости; уровни кампуса как тиры. Они не являются дополнительными требованиями пользователя.

## Интерфейс

Основная поверхность — сам сайт кампуса. Сохранить экзамены непосредственно в недельной сетке, точные дедлайны, заметки и статусы заданий, поиск и настройки. Добавить раздел «Рейтинг XP» в существующую панель на сайте. Popup остаётся быстрым входом, а не основным местом работы.

Применить палитры, фон, границы и компактные элементы Lunatica к сайту и существующим панелям. Сохранить понятные состояния фокуса, клавиатурное управление, адаптацию узкого экрана. Эффекты свечения, звёзд и анимации не нужны для первого объединённого выпуска. Не включать произвольные внешние фоны и аватары. Настройки темы, масштаба, движения, ширины и видимости Aya продолжают работать. Тема «выключена» не меняет оформление кампуса.

Состояния рейтинга: предложение вступить; XP ещё не прочитан; загрузка; пустой список; участник и его позиция; ошибка сети с повтором; подтверждение удаления. Ошибка рейтинга не блокирует расписание и локальные функции. До вступления серверу не отправляется XP или псевдоним пользователя. Просмотр публичного списка запускается при открытии раздела, не при каждом посещении кампуса.

Вступление показывает свежий XP, предлагаемый случайный псевдоним, перечень передаваемых данных и кнопку «Присоединиться». Можно выбрать другой безопасный псевдоним; рядом просьба не указывать ФИО, группу или почту. По умолчанию участие выключено. Участник вручную обновляет XP кнопкой; никаких фоновых запросов к кабинету для рейтинга.

## XP, место и тир

Источник XP — собственная страница `/ru/trajectory` (с учётом kk/en), элемент `meter.qui-levelscale[aria-valuenow]`. Найден и проверен в кабинете. Парсер требует единственное корректное целое неотрицательное значение; при отсутствии, неоднозначности, редиректе на вход или ошибке сети показывает ошибку, не подставляет ноль и не отправляет старое значение как свежее. Реальные данные кабинета не попадают в тестовые фикстуры.

Место: 1 + число участников с большим XP; равные XP дают равное место. Учитываются только вступившие и не удалённые записи. Обновление может уменьшать XP, если так показывает кампус. Дата последнего обновления видна.

Тир — существующий уровень кампуса, без новой шкалы оценивания: Hello World 0, Стажёр 400, Junior 1200, Junior+ 2400, Middle 4000, Middle+ 6000, Senior 8400, Lead 11200, Архитектор 14400, CTO 18000. XP выше последнего порога сохраняет CTO. Группировка по этим тирам и сортировка по XP дают запрошенный тир-лист. Не делать выводов об успеваемости по XP и не показывать процентиль «среди всех студентов».

## Сервер и данные

Изолированные Worker и D1 в подключённом Cloudflare-аккаунте. Перед созданием проверить текущие тарифы и доступность. Не включать платный тариф без отдельного разрешения. Никаких университетских паролей, cookies, токенов кампуса, ФИО, групп, оценок, расписаний и заметок на сервер рейтинга.

Храним случайный публичный ID участника, псевдоним, XP, время обновления и хеш секретного ключа управления. Клиент генерирует криптографически случайный секрет; сервер не возвращает его в публичных ответах. Секрет хранится в storage.local расширения и не передаётся в DOM сайта, URL или обычную резервную копию. API вызывается из background; сообщения проверяют отправителя и разрешённый тип операции. Content-script не получает секрет.

API: получение таблицы с ограниченной пагинацией; идемпотентное вступление; авторизованное обновление своей записи; получение своей позиции; авторизованное удаление. Ограниченные длина тела, диапазон XP и псевдоним; параметризованный SQL; ограничение частоты, без журналирования тел и секретов. Ограничение XP — защита целостности данных, не доказательство честности. Сервер не загружает URL, присланные клиентом. Ответы ошибок не раскрывают внутренние данные.

При вступлении сначала надёжно сохранить секрет локально, затем отправить запрос: потеря ответа допускает повтор без дубликата. Не удалять локальный секрет до подтверждённого удаления на сервере. При отсутствии сети выход остаётся незавершённым с доступным повтором. Предоставить отдельное явное сохранение/восстановление ключа управления для другого браузера с предупреждением, что он даёт право изменить или удалить запись. При потере ключа восстановление по личности не обещается. Неактивные записи удалять после 90 дней; последующие запросы не должны молча создавать нового участника без согласия.

Удаление немедленно убирает запись из действующей таблицы. Политика объясняет срок инфраструктурных резервных копий и возможные технические журналы Cloudflare согласно проверенным настройкам; не обещать мгновенное удаление всех резервных копий. Обновить политику приватности и заявления обоих магазинов до отправки. Разрешение на сервер рейтинга — только конкретный HTTPS-хост.

## Совместимость и сборка

Оставить Firefox ID `campus-night@local.qairu-tools` и существующую карточку Chrome `akkedafgaegkaccceojhpelhamfkogpa`. Выпуск расширения 2.0.0; отдельная версия исходного userscript не определяет версию расширения.

Сохранять ключ `campusNight` и все прежние данные: палитра, режим, масштаб, движение, ширина, Aya, избранное, состояние панели, экзаменационная сетка, языки/сопоставления, заметки, статусы, подготовленные сессии и история. Не вызывать storage.clear. Новые настройки добавляются без перезаписи существующих. При сбое чтения хранилища не записывать значения по умолчанию поверх данных.

Резервная копия сохраняет идентификатор `campus-night-settings`, принимает старые v1/v2 и новую v3 при необходимости. Импорт старого файла не стирает новые опции. Обычная копия не включает XP, запись рейтинга и секрет. Данные отдельного Tampermonkey-хранилища недоступны WebExtension: не обещать автоматический перенос оттуда; миграция здесь гарантируется для существующего Campus Night.

Исходники объединённого расширения, воспроизводимая сборка и код сервера входят в репозиторий форка. Сохранить исходный Lunatica и provenance, MIT и OFL, указать авторов. Не публиковать рабочие копии пользовательского кабинета, секреты или личные данные. Пакеты для обоих браузеров собираются из общего исходника.

## Проверка и выпуск

До отправки: регрессионные проверки 1.4.0; тест обновления с заполненным старым storage и v1/v2 JSON; проверки новой темы и live-переключения; XP-парсер на корректной странице, отсутствии, неоднозначности и logout; API авторизации, повторного вступления, равных XP, понижения XP, лимитов, удаления и истечения; отсутствие сетевой передачи пользовательского XP до вступления; сохранность ключа при неудачном удалении; перенос ключа; keyboard/узкий экран; lint, сборка и воспроизводимость Firefox/Chromium.

Использовать синтетические данные для сетевых испытаний и удалить тестовые записи. Не вступать в рейтинг от имени пользователя автоматически. Проверить развёрнутый API до включения его адреса в сборки. После проверок обновить обе существующие карточки магазинов по ранее данному указанию. Сообщить отдельно фактический статус отправки/модерации и доступность для установки: отправка не равна публикации.

Критерий готовности: единый интерфейс Qairu Space, учебные функции и старые данные сохранены, добровольный XP-рейтинг работает через действующий сервер с удалением записи, пакеты проверены и отправлены в оба магазина либо назван конкретный внешний блокер.
